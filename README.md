# Linux Deep Dive

Hands-on Linux labs and notes from Al-Nafi's *Linux Deep Dive* course, 
documenting my journey building strong Linux fundamentals alongside my 
cybersecurity / bug bounty path.

## About

This repo tracks lab-by-lab progress through core Linux administration and 
filesystem concepts — practiced hands-on using a local Ubuntu VM.


## Why This Repo

Understanding Linux internals — filesystem structure, permissions, ownership — 
is foundational for cybersecurity work, especially privilege escalation, 
system hardening, and vulnerability analysis.
